# Inpatient Nutrition Care Register — PWA
## MOH Kenya · SAM Inpatient Management

---

## What this is
A fully offline-capable Progressive Web App (PWA) that digitizes the MOH Inpatient Nutrition Care Register. Staff can use it on any phone or computer — no internet required after the first load.

---

## How to set it up (Step by step)

### Option A — Free hosting with GitHub Pages (Recommended)
1. Create a free account at https://github.com
2. Create a new repository called `nutrition-register`
3. Upload all files (index.html, manifest.json, sw.js) to the repository
4. Go to Settings → Pages → set source to "main branch"
5. Your app will be live at: https://YOUR-USERNAME.github.io/nutrition-register
6. Share this link with your 3 staff members

### Option B — Use locally on one device
1. Open index.html directly in Chrome or Edge on any computer
2. Data is saved on that device

---

## How staff install it on their phones

### Android (Chrome):
1. Open the link in Chrome
2. Tap the 3-dot menu → "Add to Home screen"
3. Tap "Install"
4. The app appears on the home screen like any other app
5. Works fully offline from now on

### iPhone (Safari):
1. Open the link in Safari
2. Tap the Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Tap "Add"
5. The app appears on the home screen

---

## Features
- Patient admission (all MOH fields)
- Daily weight & MUAC monitoring (Days 1–12)
- Exit / discharge recording with outcomes
- Patient search and detail view
- Dashboard with live stats
- Fully works offline — no internet needed
- Data saved on device automatically

---

## Expanding to other facilities
Each facility installs the same app from the same link. In a future version, data from all facilities can be synced to a central database. Contact your IT or data team to set this up.

---

## Data backup
Currently data is stored on each device. To back up:
- Use the Export button on the Dashboard to download a JSON file
- Keep this file safe — it contains all patient records
